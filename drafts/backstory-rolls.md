# Backstory roll tables

A writing aid for character sheets, not game data: the game never reads this file. Roll once on
each table (or pick), then keep, change or drop each result. A backstory is a handful of facts the
lines can lean on, not a biography.

## How to use it

1. Roll one result on tables 1 to 7, two on table 8 (everyday life) and one or two on table 9
   (life off the game).
2. Read them together. Keep what fits the character's type and scenes, reroll or rewrite what
   doesn't, and drop anything that fights the sheet. **The sheet always wins over a roll.**
3. Keep 5 to 7 facts. Fewer, stronger facts beat a long list.
4. Write them into the sheet's **Backstory** section (layout at the end of this file).
5. Give the seed lines and drafting tasks one or two of these facts at a time, so no single fact
   turns into the character's only topic (the Spyburd buff problem).

## Rules

- Suitable for teenagers. No politics, real-world tragedies, drugs, or mean jokes about real people.
- Named characters have two layers: the character in the world (tables 1 to 8) and the person
  who plays them (table 9). They know it's a game and have a life away from it, the way real
  MMO players drop "brb, dog" into group chat. That life is seasoning, never the focus: at most
  one line in ten, and the character stays the star. Persoper has this layer too. (Kobaldjovi's
  own sheet keeps him fully in-world; check each sheet.)
- Write table 9 lines as their own lines, never mixed into an in-character line, so a planned
  switch can turn them off (an `[ooc]` tag; not built yet). Every section still needs enough
  in-character lines to stand alone.
- Every fact is made up. Never use any real person's life details: these files
  are in a public repo.
- **Realm rule:** a named character's main lines are shared by all three realm bots, so they can't
  name a town, realm or race. Hometowns and other place facts go only in the realm sections of
  the sheet and the `.dlg` file. Everyday-life facts (table 8) are realm-free, so they suit the
  main lines best.
- Places must exist in the game. Monster types must be ones the realm really has (check in game
  if unsure).
- Dice: the d12 and d20 numbers are just for rolling. Ask Claude to roll if no dice are handy.

## Sheet layout: the Backstory section

Goes in the character sheet after "Where they come from in this world". Five to seven lines.

```
## Backstory (rolled, then edited)

- Old job: ...
- Family: ...
- Grudge: ...
- Fear: ...
- Wants: ...
- Quirk: ...
- Everyday life: ... ; ...
- Off the game (the player): ...
- Hometown (realm sections only): Midgard ... / Albion ... / Hibernia ...
- Use: at most one line in ten leans on a backstory fact; no single fact in more than a few lines.
```
